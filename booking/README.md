# Запись на съёмку — как это работает и как настроить

Клиент открывает страницу, выбирает **вид съёмки → пакет → дату → время**, оставляет контакты. Дальше всё происходит само:

- съёмка появляется в вашем Google Календаре, а занятые часы больше не предлагаются другим клиентам;
- вам приходит уведомление **в Telegram** (с кнопкой «написать клиенту в WhatsApp») и **на почту**;
- клиент получает письмо-подтверждение сразу и **письмо-напоминание за 2 дня** до съёмки.

Файлы:

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | сама страница — трогать не нужно |
| **`config.js`** | **все ваши тексты, пакеты, цены и часы работы** |
| `apps-script/Code.gs` | скрипт для вашего Google-аккаунта (календарь, почта, Telegram, напоминания) |

---

## 1. Подключение почты и календаря (10 минут, делается один раз)

1. Откройте <https://script.google.com> под тем аккаунтом Google, в календаре которого должны появляться съёмки. Нажмите **New project**.
2. Удалите содержимое файла `Code.gs` в редакторе и вставьте туда всё из `apps-script/Code.gs`.
3. Вверху файла, в блоке «НАСТРОЙКИ», при необходимости поменяйте:
   - `NOTIFY_EMAIL` — если письма должны приходить на другой адрес (пусто = на почту этого же аккаунта);
   - `CALENDAR_ID` — если съёмки должны идти в отдельный календарь, а не в основной;
   - `SEND_CLIENT_CONFIRMATION` — слать ли клиенту письмо-подтверждение (по умолчанию да);
   - `INVITE_CLIENT` — добавлять ли клиента гостем в событие (по умолчанию нет).
4. Сохраните (значок дискеты).
5. Нажмите **Deploy → New deployment**, тип **Web app**, и укажите:
   - **Execute as:** Me (ваш аккаунт)
   - **Who has access:** **Anyone** — иначе клиенты не смогут отправить заявку.
6. Нажмите **Deploy**, разрешите доступ к Календарю и Gmail (Google покажет предупреждение «Google hasn't verified this app» → *Advanced* → *Go to project*).
7. Скопируйте **Web app URL** (вида `https://script.google.com/macros/s/…/exec`) и вставьте его в `config.js`:

```js
endpoint: 'https://script.google.com/macros/s/ВАШ_АДРЕС/exec',
```

**Проверка:** в редакторе скрипта выберите функцию `testBooking` и нажмите ▶ «Run». На почту придёт тестовое письмо, а в календаре на завтра появится тестовая съёмка — её потом удалите.

> Пока `endpoint` пустой, страница всё равно работает: при отправке заявки открывается готовое письмо в почте клиента и скачивается файл `.ics` для календаря. Просто ничего не происходит автоматически.

**Важно:** после любого изменения `Code.gs` нужно снова сделать **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**, иначе изменения не подхватятся.

## 2. Уведомления вам в Telegram (5 минут, бесплатно)

1. В Telegram найдите **@BotFather**, отправьте `/newbot` и придумайте имя. Он пришлёт **токен** вида `1234567890:AAH...`.
2. Вставьте токен в `Code.gs`, строка `TELEGRAM_BOT_TOKEN`, и сохраните.
3. Найдите своего бота в поиске Telegram, откройте чат и **напишите ему любое сообщение** (иначе он не сможет вам писать первым).
4. В редакторе скрипта выберите функцию `showTelegramChatId` и нажмите ▶ «Run». Откройте **View → Logs** — там будет строка `chat_id: 123456789`.
5. Вставьте это число в `TELEGRAM_CHAT_ID`, сохраните и передеплойте (**Deploy → Manage deployments → ✏️ → New version → Deploy**).
6. Проверьте: запустите функцию `testTelegram` — в чат придёт «Telegram je povezan».

Теперь каждая новая запись приходит в чат с датой, пакетом и контактами клиента, а кнопка **«Napiši na WhatsApp»** открывает переписку с клиентом в один клик.

> Хотите получать заявки в общий чат или канал — добавьте туда бота, напишите там сообщение и снова запустите `showTelegramChatId`: у групп `chat_id` отрицательный, вставляйте его целиком, вместе с минусом.

## 3. Напоминание клиенту за 2 дня

Скрипт раз в день просматривает календарь и отправляет письмо тем, у кого съёмка через 2 дня. Чтобы это включить, **один раз** запустите в редакторе функцию `installReminderTrigger` (▶ Run) — она поставит ежедневный запуск.

Настройки в `Code.gs`:
- `SEND_CLIENT_REMINDER` — `false` полностью выключает напоминания;
- `REMINDER_DAYS_BEFORE` — за сколько дней напоминать (сейчас 2);
- `REMINDER_HOUR` — в котором часу отправлять (сейчас 10).

Если поменяете `REMINDER_HOUR`, запустите `installReminderTrigger` ещё раз — старый триггер заменится новым.

Напоминание уходит только по записям, сделанным через сайт, и только один раз: после отправки съёмка помечается, повторное письмо не придёт. Если запись отменилась — просто удалите событие из календаря, напоминание не уйдёт. Сколько писем ушло, скрипт коротко сообщает вам в Telegram.

## 4. Что вы правите в `config.js`

Открывайте файл в любом текстовом редакторе. Меняйте только текст между кавычками и числа.

**Ваши контакты** — блок `photographer`: телефон, e-mail, инстаграм. Что оставите пустым, то не показывается.

**Часы работы студии** — блок `schedule`:

```js
schedule: { days: [1, 2, 3, 4, 5], start: '10:00', end: '14:00', stepMin: 30 },
```

`days`: 0 — воскресенье, 1 — понедельник, … 6 — суббота. `stepMin` — с каким шагом предлагать начало съёмки.
У съёмок «на выезде» (`proslave`, `krstenje`) свой блок `schedule` внутри вида съёмки — он перебивает общий, поэтому там доступны и выходные, и вечернее время.

**Пакеты.** У каждого пакета:

```js
{
  id: 'baby-start',          // служебное имя, латиницей, менять не нужно
  name: 'Baby Start',        // как видит клиент
  price: 150,                // число; '' — цена не показывается
  priceFrom: true,           // необязательно: выводит «od 150 €»
  durationMin: 120,          // сколько времени занимает съёмка — влияет на свободные часы
  summary: 'Beba + roditelji | do 2 sata | 20 fotografija',
  includes: ['…', '…'],      // список «U paket je uključeno»
  notes: ['Torta nije uključena u paket.']   // необязательно, розовая плашка
}
```

Чтобы **добавить** пакет — скопируйте такой блок целиком (вместе с фигурными скобками и запятой) и поменяйте текст.
Чтобы **убрать** — удалите блок целиком.

**Прочие параметры:**
- `bufferMin` — перерыв между двумя съёмками (те же 15 минут стоят и в `Code.gs`, меняйте вместе);
- `bookAheadDays` — насколько далеко вперёд можно записаться;
- `minNoticeHours` — за сколько часов минимум принимается запись.

## 5. Как открыть страницу

Локально: открыть `booking/index.html` в браузере (или запустить `python3 -m http.server` в корне репозитория и зайти на `http://localhost:8000/booking/`).

Онлайн через GitHub Pages: в репозитории **Settings → Pages → Source: Deploy from a branch**, ветка с этим кодом, папка `/ (root)`. Через минуту страница будет доступна по адресу `https://<логин>.github.io/<репозиторий>/booking/` — эту ссылку можно ставить в шапку профиля.
